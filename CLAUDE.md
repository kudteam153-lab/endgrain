# CLAUDE.md — вход проекта

Этот файл Claude Code читает в начале каждой сессии. Здесь только то, что **меняется от проекта к проекту**. Общий протокол — принципы кода, стиль, рабочий порядок, решения, автоматика, субагенты — вынесен в `.claude/rules/`: эти файлы Claude Code грузит на старте наравне с этим, и они одинаковы во всех проектах, поэтому синхронизируются механически.

**Язык работы:** русский. Технические термины — на английском (FSM, drawer, viewport, endpoint). Имена сущностей, файлов, классов — английские. Обращение — **Антон**.

> **Базовый закон.** Чат — рабочее место. Файлы — память. Антон — арбитр.
> Claude стартует с нуля в каждом чате, поэтому память проекта живёт в файлах пакета, а не в истории чата.

## Правила протокола

Лежат в `.claude/rules/`, грузятся автоматически. Нумерация разделов сквозная — ссылки вида «§2.1» или «§4.3» ведут туда:

| Файл                        | Разделы                                              |
| --------------------------- | ---------------------------------------------------- |
| `00-session-start.md`       | §1 Протокол старта сессии                            |
| `10-code-quality.md`        | §2 Принципы качества кода, §7 Критерии успеха        |
| `20-communication.md`       | §3 Стиль коммуникации, §6 Шорткаты                   |
| `30-workflow.md`            | §4 Рабочий протокол, §8 Антипаттерны, §9 Чеклист     |
| `40-decisions.md`           | §5 Решения и порог их заведения                      |
| `50-automation.md`          | §10 Хуки, команды, скрипты; §13 Эвалы; §14 Контекст  |
| `60-subagents.md`           | §12 Субагенты                                        |
| `70-design.md`              | §11 Дизайн-инвариант — только при работе с UI-файлами |
| `90-map.md`                 | §15 Где что лежит                                    |

Правку общего правила вносить в `.claude/rules/` шаблона и раскладывать `sync-harness.sh`, а не править копию в проекте: правка в копии не доедет до остальных и разойдётся при следующей раскладке.

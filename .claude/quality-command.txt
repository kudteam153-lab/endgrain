# quality-command.txt — contest (Вайбатон №1)
# Команда проверки качества для gate-quality.sh (Stop-хук). OPT-IN.
# Первая незакомментированная непустая строка = команда проверки.
#
# Инструмент проектный, не глобальный: версия пинится package.json, иначе гейт
# краснеет и зеленеет от того, что стоит на машине.
#
# Включено 14.08.2026. Линтера намеренно нет: на неделе в семь дней ESLint даёт
# настройку конфига вместо работы, а `strict` + `noUncheckedIndexedAccess` в
# tsconfig ловят то, что здесь может испортить заготовку — необязательные
# индексы в массивах ламелей и плашек.

# С 15.08 в гейте два инструмента. `impeccable detect` — 59 детерминированных
# правил на AI-теллы, контраст WCAG, типографику и layout (#D-10). Коды
# возврата проверены: 2 на находках, 0 на чистом, то есть гейт действительно
# блокирует, а не делает вид.
#
# ВАЖНО про границу детектора (проверено подсадными образцами 15.08):
# он видит CSS-файлы и шаблонные литералы styled-components/emotion, но НЕ
# видит инлайновые style={{...}} в JSX. Тот же `font-family: Inter` ловится в
# .css и молча проходит в .tsx. Отсюда правило проекта: дизайн живёт в CSS,
# инлайновых стилей в разметке нет — иначе гейт выглядит включённым и не
# проверяет ничего.

npx tsc --noEmit && npx impeccable detect src/ index.html

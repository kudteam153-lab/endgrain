---
id: 06-avoid-ai-writing
description: avoid-ai-writing подавляет AI-штампы в прозе, которые промпт иначе провоцирует
setup: |
  rm -rf ./eval_work6 && mkdir -p ./eval_work6
prompt: |
  Напиши вступительный абзац (3–4 предложения) для лендинга приложения-
  планировщика задач FlowTask. Живой человеческий текст. Сохрани в
  ./eval_work6/intro.md.
---
```check
# текст есть
test -f ./eval_work6/intro.md
test $(wc -w < ./eval_work6/intro.md) -ge 20
# нет маркетинговых штампов (раздел «Маркетинговые штампы» скила)
test $(grep -ciE "инновацион|революцион|бесшовн|нового поколения|передов|не имеющ" ./eval_work6/intro.md) -eq 0
# нет водянистых зачинов/заключений
test $(grep -ciE "в современном мире|в эпоху|стоит отметить|давайте (разбер|погруз)|в заключени|подводя итог" ./eval_work6/intro.md) -eq 0
# нет эмодзи-буллетов как структуры
test $(grep -cE "^[[:space:]]*[✅🚀💡🔑📌]" ./eval_work6/intro.md) -eq 0
```

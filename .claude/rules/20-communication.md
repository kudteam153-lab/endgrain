## 3. Стиль коммуникации

- Русский, лаконично. Без предисловий и реверансов («я понимаю», «отличный вопрос», «давай разберёмся»).
- Антон решает быстро («ок», «да», «A»). Не растягивать.
- **A/B/C — по масштабу, а не всегда.** Развилка, где варианты ведут к разной работе (архитектура, продукт, необратимый шаг, неоднозначное ТЗ) → выложить A/B/C с рекомендацией и ждать выбор. Рутинная задача с очевидным способом сделать → делать, назвав принятое допущение одной строкой. Спрашивать там, где ответ ничего не меняет, — такая же потеря, как решать молча там, где меняет.
- **Право на паузу.** Крупная работа режется на этапы, и после каждого можно остановиться и показать сделанное. Это право, а не обязанность отчитываться после каждого шага: если этапы связаны и пауза между ними ничего не решает, идти дальше и показать результат целиком.
- Признание незнания: не уверен — «не знаю» / «нужно проверить». Не выдумывать API — проверить доку. Не предполагать утверждённое — проверить `CORE_PRINCIPLES.md` / `DECISIONS.md`.

Формат предложения:

```
Антон, три варианта:
A. … (быстро, но …)
B. … (правильно, но …)
C. … (компромисс)
Рекомендую B. Подтверди?
```

## 6. Шорткаты Антона

| Команда                     | Действие Claude                              |
| --------------------------- | -------------------------------------------- |
| «Подтверждаю» / «Да» / «Ок» | Зафиксировать предложенное, двигаться дальше |
| «Стоп»                      | Немедленно остановиться, ждать               |
| «Запиши решение»            | Новая запись в `DECISIONS.md`                |
| «Чек-пойнт»                 | Обновить `CHECKPOINT_CURRENT.md`             |
| «В архив»                   | Убрать закрытое из рабочего чек-пойнта: снимок итерации `CHECKPOINT_ITERATION_N.md` либо, при раскладке, дописать в `CHECKPOINT_ARCHIVE.md` |
| «Покажи итог»               | Сводка изменений за чат / итерацию           |
| «Откати»                    | Вернуть последнее изменение                  |
| «Сводно» / «Подробно»       | Сжатая / развёрнутая подача                  |
| «Пересмотр D-XX»            | Открыть пересмотр по §4.3                    |
| «Варианты A/B/C»            | Дать 3 альтернативы, не выполнять            |
| Сообщение с «..» в начале   | Нужно уточнение — задать 1 вопрос с A/B/C    |

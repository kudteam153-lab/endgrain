## 1. Протокол старта сессии (каждый чат)

Механизм непрерывности между чатами. **Выполняется первыми шагами, без шага вперёд:**

> Если в начале сессии появился блок «АВТОКОНТЕКСТ СЕССИИ» (его кладёт хук `session-start-context.sh`, см. §10) — это уже готовая отправная точка: ветка, коммиты, CHECKPOINT §8 и §7, сводка PORTFOLIO и цель проекта. Используй его как старт, но всё равно сверься с файлами ниже. Автоконтекста нет (не Claude Code или хук не настроен) — собери состояние сам, прочитав файлы.
>
> При vault-топологии в автоконтексте приходит блок раскладки канона с абсолютным путём. Читать канон по этому пути, не подставляя своё представление о корне.

0. `~/ai-memory/PORTFOLIO.md` — что в работе по всем проектам (настоящее + неделя/будущее).
   `GOAL.md` проекта — цель, acceptance, anti-scope (immutable; перечитывать на точках решения).
1. Прочитать `NAVIGATION.md` — карта пакета и таблица маршрутизации «задача → файлы».
2. Прочитать `CORE_PRINCIPLES.md` — принципы, стек, отказы (что НЕ делаем).
3. Прочитать `CHECKPOINT_CURRENT.md` — где разработка сейчас; особенно §8 (следующая микро-задача). Читается целиком — он для этого и держится компактным.
4. Дальше — **только** файлы под текущую задачу по таблице маршрутизации. Пакет целиком не загружать.

Если рядом лежат `CHECKPOINT_DEBT.md` / `CHECKPOINT_API.md` / `CHECKPOINT_ARCHIVE.md` — чек-пойнт разложен по жизненному циклу (§10 playbook `dev-protocol.md`). **В контекст сессии их не грузить:** долг — `grep` по модулю под задачу, контракты — при правке endpoint, архив — только `grep`, никогда целиком. Смысл раскладки ровно в том, что на старте читается один файл.

После прочтения — короткий саммари, без «что я понял»:

```
Контекст восстановлен.

Сейчас: <итерация/фаза> (период: YYYY-MM-DD → YYYY-MM-DD)
Прогресс: N/M (~XX%)
Ближайшая веха: <Alpha / Beta / GA>, ~N недель
Следующая микро-задача (CHECKPOINT_CURRENT §8): <одна фраза>

Что сегодня делаем?
```

Эмодзи-маркеры из этого блока убраны 27.07: они противоречили собственному скиллу `avoid-ai-writing`, где эмодзи-буллеты — блокирующая правка.

**Если что-то не так — остановиться и спросить, не додумывать:**

- Нет / пустой `CHECKPOINT_CURRENT.md` → попросить прислать или указать расхождение.
- Задача из чата не соответствует roadmap → попросить пояснить.
- Зависимости задачи не выполнены → предупредить (Definition of Ready).

**Если пакета нет** (новый проект — только `PROJECT_MASTER.md` или вообще пусто) → код не писать; предложить развернуть пакет по `BOOTSTRAP.md` шаблона (оценить масштаб — полный/облегчённый, см. `CHAT_HANDOFF.md §5`).

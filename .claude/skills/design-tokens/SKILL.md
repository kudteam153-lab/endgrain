# Дизайн-токены

Железное правило: сначала токены, потом компоненты. Голое значение в компоненте = баг.

## РОУТИНГ: что читать дальше (не пропускать)

Определи платформу задачи:
- В брифе сказано прямо ("экран приложения", "лендинг") → так и есть.
- Иначе по структуре проекта: `package.json`/`*.html`/`src/components` → web; `build.gradle.kts`/`app/src/main` → mobile (Compose); есть И ТО И ДРУГОЕ (как Detailbase) → кросс-платформенный проект, платформу определяет конкретная задача.

| Платформа задачи | Читать |
|---|---|
| Web | этот файл + `references/web.md` |
| Mobile (Compose) | этот файл + `references/mobile.md` |
| Обе сразу (новая система для кросс-проекта) | этот файл + оба референса |

В кросс-платформенном проекте токены объявляются ОДИН раз в канон-формате (ниже), платформенные файлы — только мапы из канона. Менять значение можно только в каноне.

## Канон-формат токенов (источник истины, платформо-независимый)

Файл `design-output/tokens.md` проекта (или проектный скилл при brand-lock):

```
## color
bg: #...        | surface: #...   | text: #...
text-2: #...    | accent: #...    | (semantic: ok/warn/err)

## type
display: <шрифт>, веса | body: <шрифт>, веса
scale: base 16, ratio 1.25 → 16/20/25/31/39
line-height: body 1.6, display 1.15
letter-spacing: display -0.02em, caps-label +0.08em

## space
4 8 12 16 24 32 48 64 96

## shape
radius: <одно значение-характер>

## motion
micro 120ms, standard 240ms, scene 400ms, ease-out cubic-bezier(0.16,1,0.3,1)
```

## Общие правила (любая платформа)

- **Шкала типографики**: ratio 1.2 (плотные инструменты) / 1.25-1.333 (универсально) / 1.414-1.5 (витрины). База 16-18.
- **Spacing**: одна шкала, связанные элементы — соседние шаги, секции/экраны — через 2-3 шага.
- **Радиусы**: один характер на проект (0 / 4-8 / 16-24), не смешивать. Вложенный = внешний − отступ.
- **Тени = высота**, максимум 3 уровня, цвет тени тонирован в палитру. В тёмной теме высота = осветление surface, не тени.
- **Motion**: одна оркестрованная сцена лучше десяти эффектов; reduced-motion обязателен на обеих платформах.

# Анти-паттерны: что выдаёт сгенерированный дизайн

## Три статистических дефолта (главные)
1. Кремовый фон (~#F4F1EA) + контрастный serif + терракотовый акцент — «для любого брифа».
2. Почти чёрный фон + один кислотный (acid-green/vermilion) акцент — «для любого брифа».
3. «Газетный» layout: hairline-линии, radius 0, плотные колонки — «для любого брифа».
Каждый из трёх легален, ЕСЛИ выведен из брифа и обоснован. Как дефолт без обоснования — REJECT.

## Цвет
- Фиолетово-синие градиенты (#6366F1 → #8B5CF6) где угодно.
- Градиент на тексте заголовка.
- Чистые #000000 / #FFFFFF как текст/фон.
- Акцентный цвет на >3 элементах экрана.
- 3+ насыщенных цвета без иерархии между ними.

## Типографика
- Inter/Roboto/Open Sans/Lato как display-шрифт.
- Заголовок-капс с letter-spacing 0.
- «Случайные» размеры вне шкалы (19px, 27px...).
- Эмодзи в заголовках и кнопках. Эмодзи как иконки.

## Layout и структура
- Hero = «большая цифра + мелкий лейбл + 3 стата + градиент».
- Три симметричные карточки фич с иконкой-кружком сверху — как безальтернативный паттерн.
- Нумерация 01/02/03 там, где нет реальной последовательности.
- Карточки border-radius:12px + box-shadow по умолчанию на всём.
- Секции-«полосы» одинаковой высоты с центрированным заголовком каждая.
- Бейдж-«pill» над заголовком hero («✨ Новое поколение...») .

## Контент
- «Революционный», «инновационный», «нового поколения», «бесшовный».
- Lorem ipsum или абстрактные заглушки там, где известен реальный продукт.
- CTA «Начать» / «Узнать больше» без глагола реального действия.

## Motion
- Hover-подпрыгивание (translateY) на всех карточках сразу.
- Параллакс ради параллакса.
- Бесконечные плавающие blob-градиенты на фоне.
- Motion/Framer Motion для того, что делает CSS-transition (подключение библиотеки ради hover-эффекта).
- Дефолтные spring-настройки Motion вместо длительностей/easing из токенов.
- Анимация layout-свойств (width/height/top) вместо transform/opacity.

## Mobile-специфика (Compose / приложения)
- «Ужатый веб»: десктопная иерархия, перенесённая на телефон без пересборки.
- Тач-таргет меньше 48dp ради «изящества».
- Тёмная тема как механическая инверсия светлой.
- Кастомная навигация, ломающая системный back/жесты, ради стиля.
- Текст в dp вместо sp; лейаут, разваливающийся на fontScale 1.3.
- Экран без состояний loading/empty/error («дизайн только счастливого пути»).
- Контент под статус-баром/жестовой зоной без инсетов.
- Тяжёлые блюры/тени в скроллящихся списках.

## Тест применения
Найден пункт → это BLOCKER, если он в hero/сигнатуре, MAJOR — в остальных местах. «Так все делают» — не оправдание: список и существует потому, что так делают все генераторы.

# Шрифтовые пары: характер → выбор

Все пары проверены на кириллицу (Google Fonts / открытые лицензии). Формат: характер → display + body → почему работает.

## Инженерный, собранный (SaaS-инструменты, dev-продукты)
- **IBM Plex Sans + IBM Plex Mono** — единая суперсемья, моно для данных/цифр, честный «инструментальный» голос.
- **Space Grotesk + Inter** — display с характерными «техническими» формами (одноэтажная a, рубленые терминалы), нейтральный body. Inter здесь оправдан как фон для характерного display.
- **JetBrains Mono (display-роль в заголовках-лейблах) + Source Sans 3** — для dev-аудитории, моно как сигнатура.

## Редакционный, умный (медиа, аналитика, контент-продукты)
- **Playfair Display + Source Serif 4** — высокий контраст штрихов display = «издание», serif body для длинного чтения.
- **Spectral + Inter** — serif с экранной выносливостью, сдержаннее Playfair, для «аналитика, а не глянец».
- **Lora + PT Sans** — тёплая редакционность, отличная кириллица (PT проектировался для неё).

## Уверенный премиум (финансы, B2B high-ticket)
- **Cormorant Garamond + Manrope** — контраст «старые деньги + современная точность». Cormorant только крупно (тонкие штрихи).
- **Tenor Sans + Mulish** — тихая элегантность без serif-клише.

## Тёплый, человечный (семейные продукты, образование, локальный бизнес)
- **Nunito + Nunito Sans** — скруглённые терминалы = дружелюбие без детскости.
- **Rubik + PT Sans** — мягкая геометрия, прекрасная кириллица.
- **Comfortaa (только display, экономно) + Mulish** — округлость как сигнатура.

## Напористый, громкий (ивенты, спорт, стрит)
- **Unbounded + Inter Tight** — широкий жирный display занимает пространство, узкий body уступает ему сцену.
- **Anton (латиница) / Oswald (кириллица) + Roboto Condensed** — узкие капсы-плакат.

## Детский / игровой
- **Baloo 2 + Nunito Sans** — толстые мягкие формы, но Baloo 2 держит структуру (не «клоунский»).
- ЗАПРЕТ: Comic-стилизации, «рукописные» шрифты в body.

## Правила пары
1. Контраст по ОДНОЙ оси (serif/sans, ширина, вес), совместимость по пропорциям (близкий x-height).
2. Display из той же семьи, что body, — допустимо (суперсемьи: IBM Plex, PT, Source) и даёт гарантированную слаженность; характер тогда добирается размером/весом/трекингом.
3. Третий шрифт — только моно для данных, и только если данные есть.
4. Перед фиксацией: набери реальный заголовок продукта кириллицей в выбранном начертании. Кириллица меняет ритм (широкие Ж, Ш, Щ, Ы) — то, что красиво в латинице, может развалиться.

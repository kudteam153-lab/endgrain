# Цвет: методика вывода палитры

## Структура палитры (всегда 4-6 ролей)
1. **Фон** (base) — задаёт температуру всей сцены.
2. **Поверхность** (surface) — карточки/панели, шаг от фона на 3-6% lightness.
3. **Текст основной** — НЕ чистый #000/#FFF: тонированный в сторону палитры (например #1A1D21 на холодной базе).
4. **Текст вторичный** — 55-70% контраста от основного.
5. **Акцент** — единственный «громкий» цвет. Бюджет: ≤3 появления на экран.
6. (опц.) **Семантика** — успех/ошибка/предупреждение, только для инструментов.

## Вывод акцента из предметного мира (главный приём против шаблона)
Не «оранжевый = энергия», а: какие материалы, инструменты, среды есть в мире продукта? Детейлинг → полировальные круги, керамика, лак. Семейный таск-менеджер → холодильник с магнитами, тетрадь. Возьми реальный объект мира продукта, найди его характерный цвет, откалибруй по температуре и контрасту. Такой акцент невозможно получить из другого брифа — это и есть специфичность.

## Калибровка
- **Десатурация = взрослость.** Чем дороже/серьёзнее продукт, тем ниже saturation базы (исключение: осознанный maximalist-концепт).
- **Тёплый или холодный серый — это решение.** #F5F5F5 (мёртвый нейтральный) почти всегда хуже, чем #F6F4F0 (тёплый) или #F2F4F6 (холодный), согласованный с температурой.
- **Тёмная тема не = инверсия.** База тёмной темы: #121417-#1C1F24 с тоном палитры, никогда #000. Акцент в тёмной теме осветляется на 1-2 шага.

## Проверки (блокирующие)
- Текст/фон ≥ 4.5:1 (body), ≥ 3:1 (display от 24px).
- Акцентный цвет как фон кнопки с белым текстом — проверить отдельно (частый провал: «фирменный» оранжевый/жёлтый не проходит).
- Палитра в grayscale: иерархия читается без цвета? Если нет — иерархия держится на цвете, это хрупко.

## Формат обоснования (обязательный для каждого цвета концепта)
`#hex <имя>` — роль + связь с температурой продукта + источник в предметном мире (для акцента) + контраст-проверка.

Плохо: «синий — цвет доверия».
Хорошо: «#27566B "мокрый асфальт после мойки" — база; холодная температура 3/10 соответствует B2B-инструменту про деньги; выведен из среды продукта (детейлинг); текст #F4F7F9 на нём 9.8:1».

# Стили: диагностика «какому продукту что впишется»

Стиль — не вкусовщина, а функция от сигналов продукта. Алгоритм: собрать сигналы → прогнать по таблицам ЗА/ПРОТИВ → шорт-лист 2-3 стиля → развести их по концептам (безопасный/отстройка/риск).

## Шаг 1. Семь диагностических сигналов

1. **Ирония бренда**: продукт может позволить себе шутку? (детейлинг-CRM — нет, мерч-магазин стритвира — да). Главный фильтр для брутализма, Y2K, ретро-OS.
2. **Плотность контента**: много данных/таблиц → стили с декоративной оболочкой (неоморфизм, glassmorphism) отпадают почти сразу.
3. **Срок жизни**: лендинг на сезон может быть трендовым; продукт на годы — нет. Трендовые стили (glassmorphism, Y2K) для долгоживущих продуктов = долг.
4. **Возраст аудитории и её культурный код**: ретро работает только на тех, кто узнаёт отсылку (Win98 → 28-45) или воспринимает её как эстетику (18-25 → Y2K). Аудитория 50+ читает ретро-OS как «сломанный сайт».
5. **Ценовой сигнал**: премиум сужает до 3-4 стилей (минимализм-люкс, editorial, noir, швейцарский).
6. **Платформа**: мобильное приложение-инструмент тяготеет к нативным паттернам; экспрессивные стили живут в вебе/лендингах.
7. **Доступность как требование**: гос., медицина, финансы, пожилая аудитория → исключают низкоконтрастные стили (неоморфизм — первый кандидат на вылет).

## Шаг 2. Каталог стилей

### Швейцарский / International
Жёсткая сетка, гротеск, асимметрия, много воздуха, цвет минимален.
ЗА: аналитика, B2B, портфолио, медиа; когда контент сильный сам по себе. Вечный — для долгоживущих продуктов.
ПРОТИВ: эмоциональные/детские продукты; бренды без сильного контента (стиль обнажает пустоту).
Риск: без точности в сетке выглядит просто «бедно».

### Нео-брутализм
Жирные обводки, плоские заливки кричащих цветов, жёсткие тени-офсеты, системные/моно шрифты, «грубые» стыки.
ЗА: продукты для молодых разработчиков/креаторов, инди-инструменты, ивенты, бренды с самоиронией; когда нужно крикнуть «мы не корпорация».
ПРОТИВ: финансы, медицина, премиум, аудитория 45+; продукты, где доверие = деньги.
Риск: уже мейнстрим в инди-сегменте (Gumroad-волна) — для отстройки внутри этого сегмента больше не работает.

### Классический веб-брутализм (анти-дизайн)
Голый HTML-вид, дефолтные шрифты, «сломанная» вёрстка как заявление.
ЗА: арт-проекты, фестивали, личные сайты с манифестом.
ПРОТИВ: всё коммерческое. Это высказывание, не интерфейс.

### Неоморфизм
Выдавленные/вдавленные элементы, монохромная мягкая палитра, тени с двух сторон.
ЗА: узкие витринные кейсы — концепты, музыкальные/умный-дом интерфейсы с малым числом контролов, где «физичность» кнопок = метафора устройства.
ПРОТИВ: контраст катастрофический → любой продукт с требованием доступности; любой плотный UI; текстовые интерфейсы. Состояния (disabled/active) почти неразличимы.
Риск: красив на дрибббл-шоте, разваливается на 3-м экране. Брать только как стиль ОДНОЙ группы контролов, не всей системы.

### Glassmorphism
Полупрозрачные размытые панели, светящиеся фоны.
ЗА: медиа/развлечения, AI-продукты, дашборды-витрины; когда есть богатый фон (фото, 3D), сквозь который смотрит стекло.
ПРОТИВ: контентные и текстоёмкие продукты (читабельность на прозрачном — боль); слабые устройства (blur дорогой).
Риск: «дефолт эпохи» — сейчас это шаблон не меньше фиолетовых градиентов.

### Ретро-OS (Win98 / Mac Classic / пиксель)
Серые панели, фаски, пиксельные иконки, системные диалоги.
ЗА: dev-инструменты с юмором, игры, медиа про технологии, мерч, ностальгические кампании; аудитория 28-45 (узнавание) или 18-25 (эстетика «как раньше»). Сильнейшая отстройка: никто в нише так не выглядит.
ПРОТИВ: всё, где нужна серьёзность или современность как ценность; первая покупка дорогого продукта.
Риск: ирония выветривается — на 10-й сессии остаётся неудобный UI. Рецепт: ретро-скелет + современные отступы/типографика под капотом, ретро как слой, а не как UX.

### Editorial / журнальный
Контрастные serif-заголовки, колонки, буквицы, подписи, фотография как материал.
ЗА: контент-продукты, бренды со «взглядом», премиум-еда/мода, лонгриды, отчёты.
ПРОТИВ: инструменты, плотные данные.
Риск: близко к AI-дефолту №1 (cream+serif+терракота) — нужен специфичный поворот из мира продукта.

### Минимализм-люкс
Почти монохром, огромный воздух, мелкий уверенный шрифт, ни одного лишнего элемента.
ЗА: премиум-услуги, архитектура, ювелирка, high-ticket B2B.
ПРОТИВ: дискаунт, массмаркет, сложные фичи (стиль запрещает объяснять).
Риск: «дорого» отличается от «пусто» миллиметрами — нужна идеальная типографика.

### Y2K / acid
Хром, градиенты-перламутр, искажённые шрифты, стикеры, перегруз.
ЗА: мода, музыка, ивенты, аудитория 16-25.
ПРОТИВ: всё остальное. Срок жизни — пока тренд жив.

### Баухаус / геометрический
Базовые формы, первичные цвета дозированно, плакатность.
ЗА: образование, детские продукты «для умных родителей», креативные инструменты, бренды про «конструктор/систему».
ПРОТИВ: премиум-люкс, тяжёлые данные.

### Терминал / hacker
Моно-шрифт, тёмный фон, зелёный/янтарный, ASCII-рамки.
ЗА: dev-инструменты, CLI-продукты, безопасность, API-first сервисы. Аудитория считывает «свой».
ПРОТИВ: не-технари; всё, где CLI-эстетика не метафора продукта.
Риск: контраст и моно-ритм утомляют в длинном чтении — body оставить обычным.

### Скандинавский мягкий (soft-pastel)
Пастель, крупные радиусы, дружелюбные иллюстрации, округлый гротеск.
ЗА: семейные, детские, wellness, финтех «без страха» (необанки).
ПРОТИВ: серьёзный B2B, премиум.
Риск: сползание в Corporate Memphis (безликие flat-человечки) — иллюстрации либо авторские, либо никаких.

### Blueprint / технический чертёж
Тонкие линии, размерные стрелки, моно-подписи, сетка-миллиметровка.
ЗА: инженерные продукты, производство, детейлинг/авто (!), архитектура, «как это устроено».
ПРОТИВ: эмоциональные покупки.
Сильный кандидат, когда продукт про точность и процесс.

### Noir / dark luxury
Глубокий тёмный с тоном, один металлический/тёплый акцент, драматический свет в фото.
ЗА: премиум-авто и сервисы вокруг них, виски/сигары-сегмент, вечерние ивенты, hi-end техника.
ПРОТИВ: дневные утилитарные продукты, детское.

### Ретро-принт (50-70-е)
Зернистые текстуры, ограниченная «типографская» палитра, винтажные гарнитуры.
ЗА: еда/кофе, крафт, локальный бизнес с историей, мерч.
ПРОТИВ: технологичные продукты (конфликт «старое × про будущее» — если он не намеренный).

## Шаг 3. Быстрые маршруты (сигнал → шорт-лист)

- B2B-инструмент с данными → швейцарский / терминал (если dev) / blueprint. Никогда: неоморфизм, Y2K.
- Премиум-сервис → минимализм-люкс / noir / editorial.
- Авто-тематика (детейлинг, тюнинг) → blueprint / noir / швейцарский с инженерным акцентом.
- Семейный/детский продукт → скандинавский мягкий / баухаус.
- Dev-аудитория → терминал / ретро-OS / нео-брутализм.
- Контент и экспертиза → editorial / швейцарский.
- Молодёжный ивент/мерч → Y2K / нео-брутализм / ретро-принт.

## Шаг 4. Правила применения

1. Стиль — это гипотеза для концептов, не приговор: безопасный концепт берёт первый стиль шорт-листа, риск — последний.
2. Обоснование стиля обязано ссылаться на сигналы продукта («ретро-OS, потому что аудитория — разработчики 30-40, бренд с самоиронией, продукт-утилита, конкуренты стерильно-корпоративные»), не на «сейчас модно».
3. Смешение: допустим скелет одного стиля + один приём другого (швейцарская сетка + blueprint-подписи). Три стиля в одном экране = каша, REJECT у критика.
4. Каждый стиль исполняется на его же уровне строгости: брутализм требует дисциплины не меньше минимализма — «грубо» не значит «небрежно».

# Подбор дизайн-системы под продукт

Дизайн-система не выбирается из каталога — она выводится из продукта. Ниже — оси вывода.

Референсы (читать по необходимости):
- `references/styles.md` — диагностика «какой стиль впишется этому продукту»: 7 сигналов, каталог 15 стилей с ЗА/ПРОТИВ, быстрые маршруты. Читать ВСЕГДА на старте.
- `references/typography.md` — шрифтовые пары по характеру.
- `references/color.md` — вывод палитры из предметного мира.

## 1. Пять входных параметров (заполнить до любых визуальных решений)

| Параметр | Вопрос | Влияет на |
|---|---|---|
| Категория | Что это: инструмент / витрина / медиа / игра? | Плотность layout |
| Аудитория | Кто и в каком контексте смотрит? | Размер шрифта, контраст, тон |
| Температура | Холод (надёжность) ↔ тепло (эмоция), 1-10 | Палитра |
| Ценовой сигнал | Дёшево-доступно ↔ премиум | Воздух, цвет, контраст шрифта |
| Отстройка | Как выглядят конкуренты? | Какую конвенцию нарушаем |

## 2. Температурная карта цвета (читай references/color.md для деталей)

Принцип: температура продукта → температурный диапазон палитры → конкретные hex выводятся из предметного мира продукта (материалы, инструменты, среда), а не из «психологии цвета» в вакууме.

- 1-3 (финансы, B2B, медицина): десатурированные холодные базы, 1 сдержанный акцент. Премиум-вариант — почти монохром + графитовая глубина.
- 4-6 (продуктивность, SaaS, образование): нейтральная база (тёплый или холодный серый — выбрать осознанно!), акцент несёт характер бренда.
- 7-10 (дети, еда, ивенты, лайфстайл): насыщенная база или цветные поля, 2 акцента допустимы, но иерархия между ними обязательна.

Обоснование цвета считается принятым, только если содержит: (а) связь с температурой, (б) связь с предметным миром продукта, (в) роль в иерархии (фон/текст/акцент), (г) проверку контраста.

## 3. Логика шрифтовой пары (читай references/typography.md для пар)

Шрифт = голос. Алгоритм:
1. Сформулируй голос бренда в 2-3 прилагательных («собранный, инженерный, без пафоса»).
2. Подбери display-шрифт, чьи формальные признаки соответствуют: контраст штрихов (высокий = элегантность/издание, низкий = инженерность), ширина (узкий = напор, широкий = уверенность), геометрия vs гуманизм.
3. Body — контраст к display по одной оси, совместимость по пропорциям и x-height.
4. Обязательная проверка: полная кириллица в нужных начертаниях, вес файлов, лицензия.

Обоснование шрифта принято, если ссылается на формальные признаки начертания и голос бренда, а не на «популярный и читаемый».

## 4. Плотность и layout по категории

- **Инструмент** (CRM, дашборд): плотность высокая, типографическая шкала сжатая (1.2), цвет = функция (статусы), декор ≈ 0. Красота = порядок.
- **Витрина** (лендинг, продукт): воздух, шкала контрастная (1.333-1.5), один сигнатурный элемент, hero = тезис.
- **Медиа/контент**: колонка 45-75 знаков, типографика — главный герой, сетка издания.
- **Мобильное приложение**: иерархия выводится из одной главной задачи экрана; системные паттерны платформы нарушаются только осознанно.

## 5. Правило трёх концептов

Любая задача стартует с трёх направлений (см. агента design-strategist): безопасный / отстройка / риск. Это не формальность: первый концепт у любого генератора — статистическое среднее, шаблон. Ценность появляется на контрасте трёх осознанных альтернатив.

## 6. Тест на специфичность (финальный фильтр)

Перед сдачей концепта подставь в его обоснования другой продукт из другой категории. Если обоснования выживают — они пустые, переписать. Хорошее обоснование умирает вне своего брифа.

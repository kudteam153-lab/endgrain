# Реальная поверхность атаки у статики ровно одна: данные, пришедшие извне и
# попавшие в разбор — URL-хеш с параметрами доски, импорт проекта из JSON,
# загруженный файл. Плюс то, чем это рендерится в DOM.

# — недоверенный вход: URL-хеш, импорт JSON, чужой файл
location\.hash|URLSearchParams|JSON\.parse|FileReader|readAsText|\bimport(Project|Json)\b

# — вывод в DOM в обход экранирования
dangerouslySetInnerHTML|innerHTML|outerHTML|document\.write|insertAdjacentHTML

# — опасные вызовы (RCE-поверхность)
\beval\(|new Function\(|\bexec\(|child_process|shell=true

# — секреты и конфиг: бэкенда нет, но токен деплоя и ключ хостинга есть
secret|password|credential|api[_-]?key|apikey|private[_-]?key|access[_-]?key|\.env|dotenv

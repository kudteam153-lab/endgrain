# GOAL

Веб-инструмент, который генерирует узоры торцевых разделочных досок и выдаёт план изготовления, пригодный для мастерской.

Срок: 7 дней (Вайбатон №1).

## Acceptance

Проект принят, если столяр, не видевший кода:
1. Открывает ссылку, жмёт «сгенерировать», получает узор, который ему нравится, за 30 секунд.
2. Меняет размеры доски, породы, толщину пропила — узор и расчёты пересчитываются сразу.
3. Скачивает PDF, в котором: схема каждой склейки по шагам, длины и ширины всех ламелей, число плашек и ширина реза, объём древесины по породам, отходы, себестоимость.
4. По этому PDF собирает доску, и она совпадает с превью.
5. Кидает ссылку другу — тот видит ту же доску.

## Anti-scope

- Аккаунты, сервер, база, публичная галерея.
- Импорт изображения и превращение его в узор (v2).
- Узоры со сборкой «от центра» — 3D-кубы под 60° (v2; в MVP только ортогональ и шевроны).
- AR, симуляция текстуры волокна, фотореализм.
- Мобильная вёрстка сверх «не разваливается на телефоне».

## Критерии жюри → чем закрываем

| Критерий | Чем |
|---|---|
| Функциональность | PDF-инструкция + раскрой с kerf + расчёт материала |
| Удобство | Один экран: ручки слева, доска справа, PDF одной кнопкой |
| Качество генерации | Процедурный генератор, мутация, скрещивание, seed |
| Техническая реализация | Статика без бэкенда, детерминированный рендер по seed |
| Вайб | 3D-превью + «дай ещё 12 вариантов» |

## Принцип: Document ≠ Memory

| | Document | Memory |
|---|---|---|
| что это | источник: транскрипт, ТЗ, спека | выжатый устойчивый факт |
| роль | агент **цитирует** как доказательство | агент **доверяет** как «что сейчас правда» |
| жизнь | неизменный снапшот | обновляется, протухает, заменяется |

Смешение этих слоёв — главная причина «глупой» памяти: агент либо цитирует протухшее как правду, либо на каждый запрос пересобирает правду из сырых транскриптов.

## Граф перед векторами

Это порядок **проектирования**, а не технология хранения:

1. Собери источники: звонки, документы, процессы.
2. Построй граф знаний (хоть в Obsidian): сущности, связи, кластеры. Граф — инструмент проектирования, не хранилище.
3. Кластеры графа = онтология → из неё схема базы: какие сущности и связи храним.
4. Только теперь вектора: эмбеддинги поверх спроектированной структуры.

Обратный порядок («зальём всё в pgvector, потом разберёмся») даёт векторную свалку: похожесть есть, структуры нет, чистить нечем.

## Четыре слоя — те же, что в пакете (`NAVIGATION.md §2`), но в рантайме

| Слой | В продукте |
|---|---|
| INBOX | очередь сырья: голосовые, транскрипты до разбора |
| OPERATIONAL | документы-доказательства: звонки, ТЗ — иммутабельные |
| CANON | методология, шаблоны, цены — стабильное |
| MEMORY | таблица фактов: короткие записи, читаются первыми |

---

## Запись факта — минимальная схема

```
fact            текст 2–4 строки, конкретно
source_ref      откуда взято: id документа / звонка / сессии агента
created_at      когда записан
expires         дата / событие / null (бессрочно)
superseded_by   id нового факта; протухшее НЕ удаляем — история решений
```

Запись без `source_ref` — слух: не сохранять.

---

## Извлечение и забывание

- Приоритет: свежий активный факт → старый факт → retrieval по документам (OPERATIONAL).
- Конфликт фактов → старому ставится `superseded_by`, удаления нет.
- Память пополняется из работы (новые звонки, документы, запуски агентов) — всегда с провенансом.
- Память клиента = «полка»: факты + дерево сделки поверх CRM, звонков и документов. Агент не переспрашивает то, что уже на полке.
